关于“不定长图形如何匹配”

针对“一段上升趋势，30 根走完 vs 40 根走完，形状一致但长度不同”的问题，实现了 TimeNormKNN：任意长度的路径线性重采样到统一 N 点并做 z-score（平移/尺度不变），再用 FAISS 余弦近邻检索，最后在多个窗口尺度上聚合投票。比固定窗口 FAISS/DTW 更能命中拉伸形态，且比全序列子序列匹配快几个数量级。

复现

cd /workspace/binance_ml
pip install --break-system-packages polars pyarrow lightgbm scikit-learn faiss-cpu torch dtaidistance
python run.py --stage full --symbols BTCUSDT ETHUSDT（下载→prepare→构建数据集→训练7模型→生成 probs→评估）
报告数据源：data/datasets/{BTC,ETH}USDT_probs.npz + final_meta.pkl

样本外协议：7 个基模型在 train/early_stop 上训练；各基模型对 meta_val 与 test 分别预测；堆叠元模型仅在 meta_val 上拟合，并在从未参与任何拟合的 test 上评测。禁用指标：总成交量、ATR。使用 polars、全列 float32/int、数据零 null。
