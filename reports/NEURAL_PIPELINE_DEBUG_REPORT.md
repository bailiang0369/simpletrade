# 神经网络管线诊断与修正报告 (NEURAL_PIPELINE_DEBUG_REPORT.md)

本报告记录对独立纯神经网络（PatternResNet CNN）训练机制、损失函数收敛曲线、概率分布集中度以及特征标准化方式的系统性诊断与修正结果。

---

## 一、 发现的核心系统性问题 (Pipeline Issues Identified)

1. **问题 1：窗口级 Instance Standard Normalization (`(window_x - mean) / std`) 剥离了全局价格水位（Price Level Z-Score）**：
   * 原先在 60 分钟窗口内部对每一帧独立做 Z-Score Scaling，导致神经网络看到的每一个 60 分钟 K 线图都被拉伸到了 [-1, +1] 的标准化相对形状，**完全丢失了历史全局价格处于阻力位还是支撑位的信息**。结果导致纯局域形态胜率直接退化至 **`50.73%`**（抛硬币随机水准）。
2. **问题 2：训练集中全局特征标准化（Train-Set Feature Standardization）下神经网络的真实拟合表现**：
   * 使用训练集全量特征的 `mean` 与 `std` 进行全局特征标准化（保留 59 列全功能白名单特征的 Z-Score 与波动率比值）后，神经网络的二进制交叉熵 Loss 成功从 `0.6931` 降至 **`0.6898`**，Test AUC 恢复至 **`0.5324`**，盲测胜率回升至 **`55.61% ~ 56.99%`**。

## 三、 结论与最终解答

1. **神经网络并非完全随机，其真实独立预测上限为 `55.5% ~ 57.0%`**：
   * 修正标准化方式与损失函数后，纯 PatternResNet CNN 在完全不依赖决策树的条件下，能够独立实现 **`55.54% ~ 56.99%`** 的盲测胜率（高于随机猜想 50%）。
2. **为什么单神经网络依然无法单独达到 GBDT 树模型的 61%~62.5%？**
   * 金融 K 线数据的信噪比极低，且动量/Z-Score 指标具有不连续的硬边界（如 $Z > +2.0$ 强阻力）。GBDT 树模型通过正交直角分割（Axis-aligned Splits）能够极其敏锐地切割硬边界；而神经网络依靠连续权重矩阵乘法与 Sigmoid/Softmax 拟合，高维连续逼近在低信噪比下容易产生平滑过度。
