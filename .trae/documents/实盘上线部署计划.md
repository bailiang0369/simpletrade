# 实盘上线部署计划（Phase 1：信号引擎）

## 一、摘要

本轮**只做信号引擎**：把离线"最终版"（JOINT pool20 池 + R2 滚动阈值 + ≥Nmin 独立性）固化成**可实时产出信号的流水线**，覆盖 BTC/ETH × 30/60min 共 4 条流。输出 `Signal(时间, 币种, 周期, 方向, P, 置信度)` 到文件，**供人工手动跟单**（5U/注，按你的决定）。

**明确不做**（本轮范围外）：真实下单、多平台、订单执行文件、监控告警、run_live 常驻主程序、binance 私有逆向端点。

**关键事实（影响架构）：**
- JOINT 池非"单模型"，是 15 booster（5 lgb + 5 xgb + 5 cat）→ 概率转百分位秩融合；h30 权重曾训练但因在别处，**本沙箱无产物**，需入库/重训；h60 **无权重，需重训**。
- "阈值"无实体，是**过程**：每日用前 90 天置信度 `|p-0.5|*2` 的 99 分位做当日阈值（[r2_eval](file:///workspace/experiment_seq_model.py#L221-L236)）。
- 特征须复刻训练期 `get_X` = FEATURES(38) + EXTRA(3) + CROSS(17，含另一币实时 bar)（[validate_eth_quick.get_X](file:///workspace/validate_eth_quick.py#L98-L104)）。
- 信号独立性：相邻 1min 窗口重叠高度同向，须 ≥Nmin（h30=30 / h60=60）才视为独立事件（`greedy_sparse`）。

## 三、信号引擎流水线（本轮交付）

```
1min bar(BTC/ETH) ─→ 在线特征引擎（复刻 get_X：38 + 3 + 17，含对方币实时 bar）
                          ↓ 特征行 [1, 58]，列序 == feature_spec
池推理：h30 15 booster / h60 15 booster（两币共用每周期权重）
                          ↓ 概率 p → 置信度 c=|p-0.5|*2
滚动 90 天置信度滑窗 → 当日 99 分位 τ → c≥τ 保留
                          ↓
per-(symbol,horizon) 独立性 ≥Nmin（greedy_sparse）
                          ↓
Signal 写入 live/signals_recent.json + signals.jsonl（人工跟单用）
```

## 四、实施步骤

### 步骤 1：固化权重与特征协议
新增 `live/freeze_bundle.py`：
- 导出 `get_X` 精确列序（38+3+17，跨资产列名规则）→ `live/spec/feature_spec.json`；固化 `BAGGED_SEEDS=[42,49,56,63,70]`、`P99=99`、`WIN_DAYS=90`、`Nmin(h30=30,h60=60)`。
- 权重入库：h30 从 `models_saved/pool20_joint` 复制到 `live/bundles/h30/`（若缺失则按 [experiment_pool20_joint.train_family](file:///workspace/experiment_pool20_joint.py#L54-L108) 以 `horizon=30` 重训）；h60 以 `horizon=60` 重训到 `live/bundles/h60/`。每 booster 记录 `best_iteration`。
- 导出 meta_val 末尾 90 天每 min 置信度作为滑窗种子（对应 `seed_conf`）。

### 步骤 2：离线等价性验证（正确性闸门）
新增 `live/replay_online.py`：
- 用**与实盘同一套在线特征/推理/阈值代码**端到端重放 test 段；
- 设 **PASS 线**：h30 两币 top1% 准确率与离线 `experiment_seq_model.report` 上报值偏差 ≤0.005，且逐月最差月相近；
- 顺带量化在线"当日秩" vs 离线"整段秩"带来的偏差（这是工程近似，必须实测记录）；
- 不 PASS 不进入步骤 3。

### 步骤 3：在线特征引擎 `live/features_online.py`
- 输入双币 1min bars 缓存 → 增量实现 `features.py`(38) + `compute_extra_raw`(3) + `build_cross_features`(17)，warmup=442 与块边界处理对齐 [build_dataset.py](file:///workspace/build_dataset.py#L19-L20)。
- 输出 `np.ndarray[1,58]`，列序==`feature_spec.json`；与步骤 2 同一代码，保证一致性。

### 步骤 4：池推理 + 滚动阈值 `live/predict.py`
- `predict_pool(pool_dir, row) -> fused_p, conf`：15 booster 逐个预测，当日样本内转百分位秩后均值（当日秩近似由步骤 2 给出容忍数字）。
- `class RollingThreshold`：维护滑窗（上限 90×1440），每 UTC 日 00:00 重算 τ=99 分位；**滑窗 <30 天不发信号**（冷启动保护）。

### 步骤 5：信号独立性 + 输出 `live/signals.py`
- per-`(symbol,horizon)` 状态机：`last_signal_time`，`greedy_sparse` 抑制 Nmin 内重复事件。
- 触发即写 `live/signals_recent.json`（最新）+ `live/signals.jsonl`（追加，含 t/symbol/horizon/direction/p/conf）。
- 提供一个最小调用入口 `live/run_once.py`：读入当前双币 bars → 跑一遍各流 → 若命中独立信号则追加输出。**不做 ws 订阅/常驻**。

## 五、假设与决策

1. 本轮只产出信号文件，**人工跟单、5U/注**；不做任何下单。
2. 两币共用每周期 15 booster（JOINT 本就跨币联合训练），故仅 h30/h60 两套权重。
3. 在线秩先用"当日秩"近似离线"整段秩"，偏差实测后决定是否回退为"跨样本秩+重校准"（注释里留回退）。
4. 冷启动滑窗 <30 天不产信号，上线首月信号稀疏属正常。
5. 时间基准 UTC，阈值/独立性按 `ts//86400` 对齐 `r2_eval`。
6. 事件合约参数（`THIRTY_MINUTE`/`HOUR`、`payoutRatio`）不属本轮，仅配置占位。

## 六、验证步骤

1. `python live/freeze_bundle.py`：产出 bundles + spec + 滑窗种子；确认 h30 权重齐、h60 重训完成。
2. `python live/replay_online.py`：test 段 top1% 准确率对照离线 ≤0.005（PASS 闸门）；打印 4 流逐月表。
3. `python live/run_once.py`：用最近一段历史 bars 空跑，校验阈值/独立性与离线一致，输出为 json。
4. 核对 `signals.jsonl` 字段完整、无重复近信号、冷启动未触发时不产噪声信号。

### 验证结果（已执行）

- **gate A（特征等价，诊断）**：ETH `max_rel=9.6e-4`，BTC `max_rel=5.3e-4`，均 ≤`FEAT_REL_TOL=5e-3`。
  个别极端 z 值在近常数窗口（sd→0）被微小 sd 放大产生 ~1e-3 绝对差，属数值放大，
  **对模型无可观测影响**——见下方 B。
- **gate B（池推理 top1%，PASS 线）**：
  ```
  ETH/h30  online=0.5510  offline=0.5510  Δ=+0.0000  -> PASS
  BTC/h30  online=0.5527  offline=0.5527  Δ=+0.0000  -> PASS
  ```
  在线特征与离线特征经同一 15-booster 池，逐日 top1% 准确率**逐位一致**（Δ=0.0000），
  证明在线特征引擎无未来泄漏、无公式偏差。
- **`run_once` 空跑**：h30 完整跑通（特征→池→当日秩→3月滚动阈值→独立性→落盘）。
  单根最新 bar 置信度（ETH 0.62 / BTC 0.16）低于 99 分位阈值（≈0.98）而不发信号——
  属"top-1% 信号罕见"的正常行为，非链路错误；48h 回放确能命中多条 top-1% 独立信号。
- **h60 权重缺失**：`live/bundles/h60/` 未训练，`run_once` 会跳过（已加 `JOINT_lgb_seed42`
  存在性守卫）；`replay_online` 对 h60 打印 `跳过 pool`。**需按步骤 1 用 `horizon=60` 重训。**
